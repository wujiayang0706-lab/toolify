什么是JSON格式化？

    
JSON（JavaScript对象表示法）是 API 和配置文件的标准数据格式。系统间传输时通常是压缩的—所有空白被去除以节省字节—对人来说不可读。格式化（也称美化或美化打印）添加换行和缩进，让结构一目了然。压缩则相反，去除所有非必要空白以生成最小的有效JSON—适用于部署前或网络传输。

常见JSON错误（及修复方法）

    
    
      
  • 尾随逗号：{"a":1,}—移除最后一项后的逗号。JSON 不允许尾随逗号。
    • 
      
  • 单引号：{'a':1}—JSON 要求双引号。用 {"a":1}。
    • 
      
  • 未加引号的键：{a:1}—键必须用双引号：{"a":1}。
    • 
      
  • 注释：// 注释—JSON 没有注释。移除它们或使用 JSONC。
    • 
      
  • 特殊字符：字符串中未转义的 Tab 或换行—转义为 \t 和 \n。
    •

常见问题

      
这个JSON格式化工具真的免费吗？
是的，完全免费且无限制。我们通过页面上的非侵入式广告维持运营。

      
我的JSON会上传到服务器吗？
不会。所有解析、格式化和压缩都在浏览器中通过JavaScript本地完成。数据不会离开您的设备。

      
能处理大型JSON文件吗？
可以，能处理几MB的文件。由于在浏览器中处理，超大文件可能稍慢，但在现代设备上运行良好。

      
支持JSONC或JSON5（带注释）吗？
不支持—本工具遵循严格 JSON（RFC 8259）。注释、单引号和尾随逗号会被标记为错误。如需严格JSON输出请先移除。

      
应该用哪种缩进？
2空格是最常见的约定。4空格对深层嵌套数据更易读。Tab 也有效—选择团队偏好的即可。

      
能自动修复损坏的JSON吗？
不能自动修复—它会准确告诉您哪里错了以便修复。自动修复可能悄然改变数据含义，因此我们改为精确报告错误。

      
手机上能用吗？
可以！格式化工具支持iOS、Android及任何现代移动浏览器。
