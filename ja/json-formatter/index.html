JSONフォーマットとは？

    
JSON（JavaScript Object Notation）はAPIや設定ファイルの標準データ形式です。システム間転送時は通常圧縮されており—バイト数削減のため空白が全削除され—人間には読めません。フォーマット（美化・整形とも）は改行とインデントを追加し、構造を一目で分かりやすくします。圧縮はその逆で、不要な空白を全削除して最小の有効JSONを生成—デプロイ前やネットワーク送信に適しています。

よくあるJSONエラー（と修正方法）

    
    
      
  • 末尾カンマ：{"a":1,}—最後の項目の後のカンマを削除。JSONは末尾カンマを許可しません。
    • 
      
  • シングルクォート：{'a':1}—JSONはダブルクォート必須。{"a":1}を使用。
    • 
      
  • クォートなしキー：{a:1}—キーはダブルクォート必須：{"a":1}。
    • 
      
  • コメント：// コメント—JSONにコメントはありません。削除するかJSONCを使用。
    • 
      
  • 特殊文字：文字列内の未エスケープのTabや改行—\tや\nとしてエスケープ。
    •

よくある質問

      
このJSONフォーマッターは本当に無料ですか？
はい、完全無料で制限なし。ツールはページ上の控えめな広告で運営しています。

      
JSONはサーバーにアップロードされますか？
いいえ。すべての解析・フォーマット・圧縮はJavaScriptによりブラウザ内でローカルに行われます。データがデバイスから外に出ることはありません。

      
大型JSONファイルに対応しますか？
はい、数MBのファイルに対応します。ブラウザ内処理のため超大ファイルは少し時間がかかりますが、モダンデバイスで問題なく動作します。

      
JSONCやJSON5（コメント付き）に対応していますか？
いいえ—当ツールは厳密なJSON（RFC 8259）に従います。コメント・シングルクォート・末尾カンマはエラーとしてフラグ付けされます。厳密なJSON出力が必要なら先に削除してください。

      
どのインデントを使うべき？
2スペースが最も一般的な慣習。4スペースは深くネストしたデータに読みやすい。Tabも有効—チームの好みで。

      
壊れたJSONを自動修復できますか？
自動修復はしません—何が悪いか正確に通知し、あなたが修正できます。自動修復はデータの意味を暗黙に変えるリスクがあるため、エラーを正確に報告します。

      
モバイルで使えますか？
はい！フォーマッターはiOS、Android、モダンなモバイルブラウザすべてで動作します。
